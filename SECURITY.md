# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security reports.

Instead, report privately via GitHub Security Advisories:
- https://github.com/unisone/claude-learner/security/advisories/new

Include:
- a description of the issue and impact
- steps to reproduce / proof of concept
- affected versions or commit hash

## Notes

This project runs a local daemon and processes Claude Code session logs. Please report anything related to:
- secret leakage
- unsafe file operations
- unexpected network access
- permissions/privilege escalation
