## The Problem

You use Claude Code daily. Sometimes it makes mistakes. You correct it. Tomorrow, it makes the same mistake again.

**Boris Cherny** (Claude Code creator) said the best teams add every mistake to their CLAUDE.md. But doing this manually is tedious.

## The Solution

Claude Learner analyzes your session history, finds patterns where you corrected Claude, and generates actionable rules for your CLAUDE.md.

```bash
npx claude-learner stats     # See your usage statistics
npx claude-learner analyze   # Find correction patterns
npx claude-learner improve   # Generate CLAUDE.md rules
npx claude-learner export    # Save to .learnings/ directory
```

## Installation

```bash
# Run directly with npx (recommended)
npx claude-learner analyze

# Or install globally
npm install -g claude-learner
```

### Requirements

- Node.js 18+
- Claude Code sessions (stored in `~/.claude/projects/`)
- OpenAI API key (optional, for enhanced analysis)

## Usage

### View Statistics

See your Claude Code usage stats:

```bash
claude-learner stats

# Output:
# Sessions: 42
# Total messages: 3,847
#   └─ User messages: 1,203
#   └─ Assistant messages: 2,644
# Date range: 1/15/2026 → 1/27/2026
# Top projects:
#   • my-app: 15 sessions
#   • api-service: 8 sessions
```

### Analyze Sessions

Find patterns where you corrected Claude:

```bash
# Analyze last 10 sessions
claude-learner analyze

# Analyze more sessions
claude-learner analyze -n 50

# Analyze all sessions
claude-learner analyze --all

# Verbose output
claude-learner analyze -v
```

### Generate Improvements

Convert patterns into CLAUDE.md rules:

```bash
# Generate improvements (uses OPENAI_API_KEY if set)
claude-learner improve

# Or provide key directly
claude-learner improve --api-key sk-...
```

### Export Learnings

Save everything to a `.learnings/` directory:

```bash
# Export as markdown
claude-learner export

# Export as JSON
claude-learner export --format json

# Custom output directory
claude-learner export -o ./my-learnings
```

## How It Works

1. **Reads Sessions** — Parses JSONL files from `~/.claude/projects/`

2. **Detects Patterns** — Looks for:
   - Explicit corrections ("no, that's wrong", "undo that")
   - Failed commands (errors, exceptions)
   - Repeated explanations
   - Rollbacks and reverts

3. **Filters Noise** — Distinguishes real corrections from casual chat

4. **Generates Rules** — Uses AI to create actionable CLAUDE.md entries

## Configuration

### Environment Variables

| Variable | Description |
|----------|-------------|
| `OPENAI_API_KEY` | OpenAI API key for enhanced analysis |
| `CLAUDE_SESSIONS_PATH` | Custom path to Claude sessions (default: `~/.claude/projects`) |

## Privacy

- **100% local** — Your session data never leaves your machine
- **OpenAI calls are optional** — Basic analysis works offline
- **No telemetry** — We don't track anything

## FAQ

<details>
<summary><b>Where are Claude Code sessions stored?</b></summary>

On macOS: `~/.claude/projects/`

Each project has its own folder with `.jsonl` session files.
</details>

<details>
<summary><b>Why am I not seeing any patterns?</b></summary>

This usually means:
- Your sessions don't have explicit corrections
- Claude Code is working well for you! 🎉

For best results, make corrections explicit: "No, use X instead" rather than just manually fixing.
</details>

<details>
<summary><b>Can I use this without an OpenAI key?</b></summary>

Yes! Basic pattern detection works offline. The OpenAI key enables smarter analysis and better rule generation.
</details>
